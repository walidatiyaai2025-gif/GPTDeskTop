# UI-024 — Compact Selected Monitor status strip

## Goal
Return the right-side operator pane to the **Saved Monitors** list instead of permanently reserving 32% of its height for selected-monitor details.

## Implementation
- `CompactSelectedMonitorExperience` locates the existing Selected Monitor editor after `MainForm` is built.
- The Saved Monitors row becomes the only flexible-height row (`100%`).
- Selected Monitor becomes a fixed **58 logical px** DPI-aware strip.
- The existing **Selected Monitor** heading, live `_editorLabel` summary, and original **Edit Selected Monitor** button are re-positioned into the compact strip.
- The permanent Auto reply / Enabled / Summary label rows are hidden from the main surface; their underlying controls and state updates remain intact.
- The original edit button is reused without attaching a replacement Click handler, so `MainForm.EditSelectedMonitorSettingsAsync` remains the behavior owner.
- The compact height and widths are recalculated after `DpiChangedAfterParent`.

## Acceptance
- Saved Monitors receives all flexible vertical space.
- The selection strip remains fixed-height rather than taking a percentage of the pane.
- The live selected-monitor summary remains visible.
- Edit Selected Monitor remains directly available and behaves exactly as before.
- No monitor runtime/database/persistence behavior is changed.
- Merge only after the established CI gates are green.
