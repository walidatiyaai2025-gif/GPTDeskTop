# UI-008 — History status font resource lifecycle

Issue: #117

Implementation branch: `agent/batch-ui-resource-lifecycle-5`

Status: **IN PROGRESS**

## Objective

Remove per-formatting `Font` allocation from `HistoryWorkspaceControl.FormatStatusCell` while preserving existing category colors and bold status typography.

## Implementation contract

1. History workspace owns one bold status font.
2. `FormatStatusCell` reuses the owned font and allocates no font during painting.
3. The font is disposed with the control lifecycle.
4. Existing Issues / Success / Deferred / Other status colors remain unchanged.
5. Regression coverage locks reuse and disposal.

## Compatibility

No history filtering/export semantics, SQLite schema, monitoring, recovery, delivery or release-publisher behavior changes.

## Validation required before merge

The final batch PR head must pass all eight established repository workflows.
