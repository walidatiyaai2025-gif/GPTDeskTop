# RST-001 — Persist and resume last working state

Status: IN PROGRESS
Issue: #203

## Goal
Preserve the last effective GPTDeskTop working configuration across close/restart and automatically continue from the last safe point.

## Invariants
- Never duplicate a previously delivered development message/task after restart.
- Preserve intentional stopped/paused state.
- Restore active monitors/settings/bindings when they were active before shutdown.
- Rebind to the saved ChatGPT conversation/target when possible.
- Use persisted state as the source of truth; restart recovery must remain idempotent.

## Validation
- Add regression coverage for persisted active-state resume.
- Keep existing crash recovery, development delivery, passive wait, hidden Chrome, Release x64, message reload, task recovery, and build gates green.
