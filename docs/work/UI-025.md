# UI-025 — Compact primary workspace section headers

## Goal
Reclaim fixed vertical space on the primary GPTDeskTop operator surface while retaining clear headings for the two core workspace lists.

## Implementation
- `CompactPrimarySectionExperience` targets only **Open ChatGPT Conversations** and **Saved Monitors** on `MainForm`.
- The existing 24px subtitle row is collapsed to zero height and the grid/content row receives all remaining flexible height.
- Section titles remain visible in a 28 logical px DPI-aware header.
- Existing subtitle text is retained as both a title tooltip and `AccessibleDescription` instead of being permanently rendered.
- Card padding is reduced without changing the underlying grid controls or their behavior.
- Dimensions are reapplied after `DpiChangedAfterParent`.
- Live Activity, Stored History, Runtime Health and other on-demand surfaces are intentionally not targeted.

## Acceptance
- Both primary section titles remain visible.
- Primary fixed header chrome is reduced and lists gain the reclaimed height.
- Subtitle guidance remains discoverable through tooltip/accessibility metadata.
- Conversation/monitor selection, persistence, runtime and database behavior are unchanged.
- Merge only after the established CI gates are green.
