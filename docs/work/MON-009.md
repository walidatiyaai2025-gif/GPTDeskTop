# MON-009 — Monitor Runtime Cancellation Resource Cleanup

Issue: #111

Implementation branch: `agent/mon-009-runtime-cancellation-disposal`

Status: **IN PROGRESS**

## Objective

Ensure every monitor runtime releases its owned `CancellationTokenSource` whether it is stopped explicitly or terminates by itself because startup/runtime work ends.

## Root cause

Before MON-009, `StopMonitorAsync` was the only path that disposed the runtime cancellation source. The worker `finally` removed self-terminated runtimes from `_running` but did not dispose the owned source, so transient startup exits and fatal/natural worker exits leaked an app-lifetime runtime resource.

A naive worker-side `Dispose()` would introduce a second race: Stop can read the runtime and then lose a race to worker finalization, causing `Cancel()` to run against an already-disposed source. Cleanup therefore needs explicit ownership rather than independent disposal from both paths.

## Implementation contract

1. Stop claims cleanup ownership while `_sync` still protects the runtime lookup.
2. Stop claims ownership before calling `Cancellation.Cancel()`.
3. Once Stop owns cleanup, worker `finally` must not remove or dispose that runtime.
4. Stop awaits the worker, identity-checks final removal, and then disposes the old runtime cancellation source.
5. A self-terminating worker that is not owned by Stop removes only its matching runtime instance, disposes its cancellation source, and publishes the Running-state change.
6. A replacement runtime can never have its resources disposed by an older worker.
7. MON-008 per-monitor Start/Stop serialization remains unchanged.

## Regression coverage

`ChatMonitorRuntimeCleanupTests.cs` locks:

- cleanup ownership is claimed before cancellation;
- worker completion happens before Stop-side disposal;
- self-termination requires token identity and `!StopOwnsCleanup` before removal/disposal;
- running-state notifications are emitted by the cleanup owner;
- `MonitorRuntime` carries explicit cleanup ownership state.
