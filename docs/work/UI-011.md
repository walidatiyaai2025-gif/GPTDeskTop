## Objective

Ensure asynchronous blocker/conversation discovery cannot outlive `MonitorIdentityRepairForm` and mutate a disposed dialog.

## Delivered contract

1. The dialog owns a lifetime `CancellationTokenSource`.
2. Each discovery call links the existing five-second operational timeout to the dialog lifetime.
3. Database and Chrome CDP discovery share that linked token.
4. Lifetime cancellation is treated as normal teardown.
5. Post-await UI mutation is blocked during disposal.
6. The lifetime source is cancelled and disposed with the form.
7. Existing invalid-identity, duplicate-owner and safe rebind behavior remains unchanged.
