# UI-007 — MainForm runtime-status font resource lifecycle

Issue: #112

Implementation branch: `agent/ui-007-mainform-status-font`

Status: **DONE / VERIFIED / MERGED**

## Objective

Remove the remaining per-formatting GDI-backed `Font` allocation from the Saved Monitors Runtime column while preserving the existing Running/Stopped visual presentation.

## Root cause

UI-006 removed per-formatting font allocation from `HomeMetricsService`, but `MainForm.FormatMonitorCell` independently continued to create a new bold `Font` on every `DataGridView.CellFormatting` callback. Repaint, scrolling, selection/invalidation and live runtime-state refreshes could therefore create repeated GDI font allocations during long-running operation.

## Delivered implementation

1. MainForm owns one bold Runtime-status font for its lifetime.
2. `FormatMonitorCell` reuses that owned font and contains no `new Font(...)` allocation.
3. Running/Stopped colors and typography remain unchanged.
4. The owned font is disposed during the completed MainForm shutdown lifecycle.
5. `MainFormStatusFontResourceRegressionTests` locks both no-per-paint allocation and explicit resource disposal.
6. No monitoring, CDP, recovery, delivery, SQLite, setup or release-publisher behavior changed.
