# UI-010 — History refresh lifetime cancellation

Issue: #120

Implementation branch: `agent/batch-ui-resource-lifecycle-5`

Status: **IN PROGRESS**

## Objective

Ensure asynchronous persisted-history refresh work cannot outlive `HistoryWorkspaceControl` and mutate controls after teardown.

## Implementation contract

1. The control owns a lifetime `CancellationTokenSource`.
2. `GetRecentLogsAsync` receives the lifetime token.
3. Post-await UI mutation is blocked when disposed, disposing or lifetime-cancelled.
4. Lifetime cancellation is normal teardown and is not logged or shown as an error.
5. The lifetime source is cancelled before child-control teardown and then disposed.
6. Normal Refresh, filtering, selection, copy and CSV export behavior remains unchanged.
